# Fase 5B: NFC-e (provedor fiscal simulado) - Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Toda venda paga de um mercado com NFC-e ligada gera um documento fiscal emitido em segundo plano, com retry quando o provedor falha e estado visível no painel; o cliente pode informar o CPF no carrinho; a venda nunca deixa de estar paga por causa da nota.

**Architecture:** Monólito Next.js sobre as fases 1 a 5A. Interface `FiscalProvider` (ao lado de `PaymentProvider` e `CardProvider`) com o adaptador `fake-fiscal`. `confirmPayment` grava um `fiscal_documents` `pending` na mesma transação (dentro de um savepoint, para nunca derrubar o pagamento); a rota `POST /api/internal/reconcile`, já chamada a cada minuto, processa a fila (`processFiscalQueue`) com retry de espera crescente. CPF opcional guardado na venda; painel mostra e reemite.

**Tech Stack:** Next.js 15, React 19, TypeScript, Postgres 16, `postgres` (postgres.js), `zod`, `vitest`, `tsx` (todos já instalados). Nenhuma dependência nova.

**Spec:** `docs/superpowers/specs/2026-10-03-fase-5b-nfce-design.md` (spec geral: `docs/superpowers/specs/2026-10-01-market77-design.md`)

## Global Constraints

- Stack: Next.js + TypeScript, Postgres com Row Level Security; migrations em SQL puro, sem ORM. Nenhuma dependência nova. Só a migration `0007_nfce.sql` muda o banco.
- Todo acesso a dados de negócio passa por `withOrg()`. O `adminSql` só descobre organização e id dos documentos vencidos na fila fiscal (e aparece em testes).
- Pagamento confirmado nunca falha nem fica lento por causa da NFC-e: `enqueueFiscalDocument` roda dentro de `tx.savepoint` e engole qualquer erro (registra com `console.error`).
- Mercado sem `nfce_enabled` (padrão falso) não cria documento nenhum; nada muda para ele. Só `tax_regime = 'simples'` emite; `normal` vira `error` com `unsupported_regime`.
- Um documento por venda (`unique (sale_id)`). A referência no provedor é o id do documento; antes de emitir, a fila consulta `getByRef` (resposta perdida nunca emite duas notas). Cada rodada de processamento de um documento incrementa `attempts`.
- Retry: espera `min(2^(attempts-1), 60)` minutos (`backoffMinutes`), no máximo 8 tentativas (`MAX_ATTEMPTS = 8`); a 8ª falha por indisponibilidade vira `error`. Rejeição do provedor e dados inválidos viram `error` na hora, sem retry. `next_attempt_at` é sempre calculado a partir do `now` recebido, nunca do relógio do banco.
- Foto dos dados (`payload`) gravada na hora da venda e refeita só em `reissueFiscalDocument`. Campos fiscais ausentes ficam `null` na foto e são recusados em `validatePayload`.
- CPF: 11 dígitos com dígito verificador, CNPJ: 14 dígitos com dígito verificador (`normalizeCpf`, `normalizeCnpj`). O CPF só aparece mascarado (`***.982.247-**`) no totem e no painel.
- O adaptador `fake-fiscal` e a rota `/api/dev/fake-fiscal/mode` recusam funcionar com `NODE_ENV=production`. Nenhuma credencial real no repositório.
- Entradas ruins nunca dão 500: JSON quebrado e CPF inválido viram 400, ids malformados e vendas de outro totem ou organização viram 404, venda fora do carrinho vira 409.
- Interface em português do Brasil. Nenhum emoji em código, commits ou arquivos. Valores monetários em centavos.
- Comportamento de Pix, cartão, lote e validade e todos os testes existentes continuam como estão (única edição em teste existente: a resposta da rota `reconcile` ganha o campo `fiscal`).
- Fora desta fase: cancelamento de nota, contingência offline, regime normal, CSC e credenciais por organização, envio da nota por e-mail, provedor fiscal real.

## Review Focus

1. Pagamento confirmado com NFC-e ligada e uma falha interna ao enfileirar: o pagamento e o estoque seguem confirmados e a transação continua usável (Tarefa 4).
2. Provedor responde tarde ou perde a resposta depois de emitir: o retry acha a nota por `getByRef` e nunca emite duas (Tarefa 5).
3. Dois processadores da fila ao mesmo tempo: cada documento é emitido uma só vez, sem números repetidos (Tarefa 5).
4. Dados inválidos (CPF, CNPJ, inscrição estadual, UF, NCM ausente, regime normal): `error` imediato com causa legível, nunca retry infinito; o dono corrige e reemite (Tarefas 5 e 6).
5. Totem: CPF malformado, JSON quebrado, id malformado, venda de outro totem ou fora do carrinho: sempre 4xx, nunca 500 (Tarefa 7).
6. Mercado com NFC-e desligada e produtos antigos sem NCM: nenhum documento, nenhuma falha em listagens ou vendas (Tarefas 1, 4 e 6).

```sql
  ADD COLUMN nfce_enabled boolean NOT NULL DEFAULT false,
  ADD COLUMN state_registration text,
  ADD COLUMN uf text CHECK (uf ~ '^[A-Z]{2}$'),
  ADD COLUMN tax_regime text NOT NULL DEFAULT 'simples' CHECK (tax_regime IN ('simples', 'normal')),

ALTER TABLE products

  ADD COLUMN cest text CHECK (cest ~ '^[0-9]{7}$'),
  ADD COLUMN cfop text NOT NULL DEFAULT '5102' CHECK (cfop ~ '^[0-9]{4}$'),

  ADD COLUMN unit text NOT NULL DEFAULT 'UN' CHECK (char_length(unit) BETWEEN 1 AND 6),
  ADD COLUMN origin smallint NOT NULL DEFAULT 0 CHECK (origin BETWEEN 0 AND 8);

ALTER TABLE sales ADD COLUMN customer_cpf text CHECK (customer_cpf ~ '^[0-9]{11}$');

CREATE TABLE fiscal_documents (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  org_id uuid NOT NULL,
  sale_id uuid NOT NULL,
  market_id uuid NOT NULL,
  status text NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'issued', 'error')),
  attempts integer NOT NULL DEFAULT 0,
  next_attempt_at timestamptz NOT NULL DEFAULT now(),
  last_error text,
  payload jsonb NOT NULL,
  provider text,
  external_id text,
  number integer,
  access_key text,
  danfe_url text,
  issued_at timestamptz,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now(),
  UNIQUE (sale_id),
  UNIQUE (id, org_id),
  FOREIGN KEY (sale_id, org_id) REFERENCES sales (id, org_id),
  FOREIGN KEY (market_id, org_id) REFERENCES markets (id, org_id)
);
CREATE INDEX fiscal_documents_due_idx ON fiscal_documents (next_attempt_at) WHERE status = 'pending';
CREATE UNIQUE INDEX fiscal_documents_external_idx
  ON fiscal_documents (provider, external_id) WHERE external_id IS NOT NULL;

ALTER TABLE fiscal_documents ENABLE ROW LEVEL SECURITY;
CREATE POLICY tenant_isolation ON fiscal_documents
  USING (org_id = nullif(current_setting('app.org_id', true), '')::uuid)
  WITH CHECK (org_id = nullif(current_setting('app.org_id', true), '')::uuid);
```

```ts
const digits = (s: string) => s.replace(/\D/g, "");
const allSame = (d: string) => /^(\d)\1+$/.test(d);

function cpfDigit(n: number[], len: number): number {
  const sum = n.slice(0, len).reduce((a, x, i) => a + x * (len + 1 - i), 0);
  return ((sum * 10) % 11) % 10;
}

/** The 11 digits of a valid CPF, or null. */
export function normalizeCpf(input: string): string | null {
  const d = digits(input);
  if (d.length !== 11 || allSame(d)) return null;
  const n = [...d].map(Number);
  return cpfDigit(n, 9) === n[9] && cpfDigit(n, 10) === n[10] ? d : null;
}

const W1 = [5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2];
const W2 = [6, ...W1];

function cnpjDigit(n: number[], w: number[]): number {
  const r = w.reduce((a, x, i) => a + x * n[i], 0) % 11;
  return r < 2 ? 0 : 11 - r;
}

/** The 14 digits of a valid CNPJ, or null. */
export function normalizeCnpj(input: string): string | null {
  const d = digits(input);
  if (d.length !== 14 || allSame(d)) return null;
  const n = [...d].map(Number);
  return cnpjDigit(n, W1) === n[12] && cnpjDigit(n, W2) === n[13] ? d : null;
}

/** 52998224725 -> ***.982.247-** */
export function maskCpf(cpf: string): string {
  return `***.${cpf.slice(3, 6)}.${cpf.slice(6, 9)}-**`;
}
```

```ts
import type postgres from "postgres";
import type { Tx } from "@/db/tenant";
import type { FiscalPayload } from "@/fiscal/provider";
import { AppError } from "@/lib/errors";

type Built = { orgId: string; marketId: string; enabled: boolean; payload: FiscalPayload };

/** The fiscal snapshot of a sale: emitter, customer and items as they are right now. */
export async function buildPayload(tx: Tx, saleId: string): Promise<Built> {
  const [s] = await tx`
    select s.org_id, s.market_id, s.total_cents, s.paid_at, s.customer_cpf,
      m.nfce_enabled, m.cnpj, m.state_registration, m.uf, m.tax_regime, m.nfce_series
    from sales s join markets m on m.id = s.market_id where s.id = ${saleId}`;
  if (!s) throw new AppError("sale_not_found");
  const items = await tx`
    select si.product_name, si.quantity, si.unit_price_cents, p.ncm, p.cest, p.cfop, p.csosn, p.unit, p.origin
    from sale_items si
    join market_products mp on mp.id = si.market_product_id
    join products p on p.id = mp.product_id
    where si.sale_id = ${saleId} order by si.product_name, si.id`;
  const [pay] = await tx`
    select method from payments where sale_id = ${saleId} and status = 'confirmed' order by created_at desc limit 1`;
  const payload: FiscalPayload = {
    emitter: {
      cnpj: (s.cnpj as string | null) ?? null,
      stateRegistration: (s.state_registration as string | null) ?? null,
      uf: (s.uf as string | null) ?? null,
      series: s.nfce_series as number,
      regime: s.tax_regime as string,
    },
    customer: s.customer_cpf ? { cpf: s.customer_cpf as string } : null,
    items: items.map((i) => ({
      description: i.product_name as string,
      ncm: (i.ncm as string | null) ?? null,
      cest: (i.cest as string | null) ?? null,
      cfop: i.cfop as string,
      csosn: i.csosn as string,
      unit: i.unit as string,
      origin: i.origin as number,
      quantity: i.quantity as number,
      unitPriceCents: i.unit_price_cents as number,
      totalCents: (i.quantity as number) * (i.unit_price_cents as number),
    })),
    totalCents: s.total_cents as number,
    paymentMethod: (pay?.method as string | undefined) ?? "pix",
    paidAt: (s.paid_at as Date).toISOString(),
  };
  return { orgId: s.org_id as string, marketId: s.market_id as string, enabled: s.nfce_enabled as boolean, payload };
}

/**
 * Queues the fiscal document of a paid sale (when the market issues NFC-e). Runs inside a savepoint
 * and swallows every error: a payment that is already confirmed must never fail because of the invoice.
 */
export async function enqueueFiscalDocument(
  tx: Tx,
  saleId: string,
  now: Date,
  build: (tx: Tx, saleId: string) => Promise<Built> = buildPayload,
): Promise<void> {
  try {
    await tx.savepoint(async (sp) => {
      const b = await build(sp, saleId);
      if (!b.enabled) return;
      await sp`
        insert into fiscal_documents (org_id, sale_id, market_id, payload, next_attempt_at, updated_at)
        values (${b.orgId}, ${saleId}, ${b.marketId}, ${sp.json(b.payload as unknown as postgres.JSONValue)}, ${now}, ${now})
        on conflict (sale_id) do nothing`;
    });
  } catch (e) {
    console.error("fiscal enqueue failed for sale", saleId, e);
  }
}
```

```ts
export const MAX_ATTEMPTS = 8;

/** 1, 2, 4, 8, 16, 32, 60, 60 minutes after the 1st, 2nd, ... failure. */
export const backoffMinutes = (attempts: number): number => Math.min(2 ** (attempts - 1), 60);

type Invalid = { code: string; message: string };
const bad = (code: string, message: string): Invalid => ({ code, message });

/** The first reason this snapshot cannot be issued, or null. Nothing here can be fixed by retrying. */
export function validatePayload(p: FiscalPayload): Invalid | null {
  if (p.items.length === 0) return bad("empty_sale", "Venda sem itens.");
  if (p.emitter.regime !== "simples") {
    return bad("unsupported_regime", "Só o Simples Nacional emite NFC-e nesta versão.");
  }
  if (!p.emitter.cnpj || !normalizeCnpj(p.emitter.cnpj)) return bad("invalid_cnpj", "CNPJ do mercado inválido.");
  if (!p.emitter.stateRegistration) return bad("missing_state_registration", "Inscrição estadual do mercado ausente.");
  if (!p.emitter.uf) return bad("missing_uf", "UF do mercado ausente.");
  if (p.customer && !normalizeCpf(p.customer.cpf)) return bad("invalid_customer_cpf", "CPF do cliente inválido.");
  const noNcm = p.items.find((i) => !i.ncm);
  if (noNcm) return bad("missing_ncm", `Produto sem NCM: ${noNcm.description}.`);
  return null;
}

async function markError(tx: Tx, id: string, attempts: number, text: string, now: Date): Promise<void> {
  await tx`
    update fiscal_documents set status = 'error', attempts = ${attempts}, last_error = ${text}, updated_at = ${now}
    where id = ${id}`;
}

/**
 * One attempt at one document, under a row lock that other processors skip.
 * ponytail: the provider call runs inside the transaction, like the other providers; the 5 s timeout bounds the lock.
 */
async function processOne(tx: Tx, id: string, provider: FiscalProvider, now: Date): Promise<boolean> {
  const [doc] = await tx`
    select id, attempts, payload from fiscal_documents
    where id = ${id} and status = 'pending' and next_attempt_at <= ${now}
    for update skip locked`;
  if (!doc) return false;
  const attempts = (doc.attempts as number) + 1;
  try {
    const payload = doc.payload as FiscalPayload;
    const invalid = validatePayload(payload);
    if (invalid) {
      await markError(tx, id, attempts, `${invalid.code}: ${invalid.message}`, now);
      return true;
    }
    // Ask first: a lost answer must not turn into a second note.
    const issued = (await withTimeout(provider.getByRef(id))) ?? (await withTimeout(provider.issueNfce(id, payload)));
    await tx`
      update fiscal_documents set status = 'issued', attempts = ${attempts}, provider = ${provider.name},
        external_id = ${issued.externalId}, number = ${issued.number}, access_key = ${issued.accessKey},
        danfe_url = ${issued.danfeUrl}, issued_at = ${now}, last_error = null, updated_at = ${now}
      where id = ${id}`;
  } catch (e) {
    if (e instanceof FiscalRejected) {
      await markError(tx, id, attempts, `${e.code}: ${e.message}`, now);
    } else if (attempts >= MAX_ATTEMPTS) {
      await markError(tx, id, attempts, `unavailable: Provedor fiscal indisponível após ${MAX_ATTEMPTS} tentativas.`, now);
    } else {
      const next = new Date(now.getTime() + backoffMinutes(attempts) * 60_000);
      const why = e instanceof Error ? e.message : String(e);
      await tx`
        update fiscal_documents set attempts = ${attempts}, next_attempt_at = ${next},
          last_error = ${`retry: ${why}`}, updated_at = ${now}
        where id = ${id}`;
    }
  }
  return true;
}

/** Issues every pending document that is due. Meant for POST /api/internal/reconcile, once a minute. */
export async function processFiscalQueue(
  now: Date = new Date(),
  limit = 50,
  provider?: FiscalProvider,
): Promise<number> {
  const due = await adminSql`
    select id, org_id from fiscal_documents
    where status = 'pending' and next_attempt_at <= ${now} order by next_attempt_at limit ${limit}`;
  if (due.length === 0) return 0;
  const p = provider ?? getFiscalProvider();
  let done = 0;
  for (const d of due) {
    try {
      if (await withOrg(d.org_id as string, (tx) => processOne(tx, d.id as string, p, now))) done++;
    } catch (e) {
      console.error("fiscal document failed", d.id, e); // one bad document must not stop the queue
    }
  }
  return done;
}

const uuidRe = /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

/** Queues a document with an error again, with a fresh snapshot of today's registration. */
export async function reissueFiscalDocument(tx: Tx, saleId: string, now: Date): Promise<void> {
  if (!uuidRe.test(saleId)) throw new AppError("not_found");
  const [doc] = await tx`select id, status from fiscal_documents where sale_id = ${saleId} for update`;
  if (!doc) throw new AppError("not_found");
  if (doc.status !== "error") throw new AppError("invalid_input", "only documents with an error can be reissued");
  const { payload } = await buildPayload(tx, saleId);
  await tx`
    update fiscal_documents set status = 'pending', attempts = 0, last_error = null, next_attempt_at = ${now},
      payload = ${tx.json(payload as unknown as postgres.JSONValue)}, updated_at = ${now}
    where id = ${doc.id}`;
}
```
